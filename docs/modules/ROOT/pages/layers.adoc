= Layers

Think in stacked concerns. Do not collapse them into one mega-project.

[cols="1,2,2", options="header"]
|===
| Layer | Problem | OpenShellOrg home

| Flag / invocation syntax
| GNU vs BSD vs Windows CLI fracture
| SOS in `open-shell-org` (+ certification)

| Process data model
| Byte streams as the only pipe currency
| This repo + endorse Nushell; companions like `nu-require`

| Terminal presentation protocol
| ANSI grid vs reflowable / semantic blocks
| Notes here; implement in terminal emulators upstream


| Shell display / control layers
| stdout polluted by TUIs; paste runs blind; no input routing
| xref:shell-display-layers.adoc[Open Shell layers plan]; Nushell fork + shell-host
| Session env freshness
| Stale PATH/env after installs; host inheritance; broken `refreshenv`
| Planned `env-refresh` + `shell-host` (xref:shell-host-and-env-refresh.adoc[plan]); DevCentr consumes

| Product environment orchestration
| What a developer machine should install/configure
| Dev-Centr (not OpenShellOrg)

| Document play / argv spawn
| Play a procedure without wrapping every command in a shell dialect
| Cousin: Dev-Centr PlayTime (xref:playtime-at-the-shell-boundary.adoc[essay]). Stance (argv vs shell) is ours to document. Engine stays in `scriptbook` while it is built.
|===
