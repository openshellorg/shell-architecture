== Role

https://github.com/openshellorg/open-terminal[`openshellorg/open-terminal`] is the **greenfield D terminal host** for OpenShellOrg:

* Session surfaces in **separate OS windows**
* Calling window = **session index** (tabs and/or thumbnail preview grid)
* Tabs **decoupled** from the PTY surface (unlike classic Windows Terminal)

Near-term **env-refresh** and first-class **host-chrome negotiation** remain on the Windows Terminal fork (`openshellorg/terminal`). Do not retire the fork until open-terminal reaches parity on those slices.

== Product model

----
+---------------------------+          +------------------+
|  CALLING / INDEX WINDOW   |          | SESSION WINDOW B |
|  tabs  and/or  thumb grid |  owns    |  PTY + vt cells  |
|  (chrome / session index) | -------> |  (live surface)  |
+---------------------------+          +------------------+
----

Detail lives in the host repo: link:https://github.com/openshellorg/open-terminal/blob/main/docs/PRODUCT-MODEL.adoc[PRODUCT-MODEL.adoc].
