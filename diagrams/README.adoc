= Diagram ownership and synchronization

The four OpenShell-native diagrams remain generated from the `.mmd` and Themed SVG manifests under `docs/modules/ROOT/partials/diagrams/`.

The twelve PlayTime diagrams are fixed consumer artifacts owned by https://github.com/dev-centr/scriptbook/tree/97534371f0da8d81e495cb4cc069704902dbdd69[Scriptbook commit `9753437`]. This repository preserves:

* stable `.svg` URLs containing standalone-adaptive light/dark artifacts;
* matching `.host.svg` artifacts for progressive delivery;
* the prior hand-authored illustrations as `.fixed.svg`.

Run `pnpm playtime:sync` to read that exact commit from the local Scriptbook git object database. Set `PLAYTIME_SOURCE` when the checkout is elsewhere. The command never reads Scriptbook's working tree.

Run `pnpm test` to regenerate-check only the four OpenShell-native diagrams and validate all 36 committed PlayTime assets against `playtime-artifacts.json`. The checksum, XML, safety, accessibility, and adaptive/host checks do not require a sibling checkout.
